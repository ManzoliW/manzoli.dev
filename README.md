# 🌐 manzoli.dev

Personal portfolio and website of **William Manzoli**, a Senior Frontend Engineer based in São Paulo, Brazil.

✨ **Live Demo:** [manzoli.dev](https://www.manzoli.dev)

---

## 🛠️ Tech Stack

* **Framework:** [Nuxt 3](https://nuxt.com/) (Vue 3, SSR, Nitro)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Animations:** [GSAP](https://gsap.com/) & [Motion-V](https://github.com/hanno-mensch/motion-v)
* **WebGL/Canvas:** [OGL](https://github.com/oogl/ogl) (Minimal WebGL library)
* **Icons & Fonts:** Nuxt Fonts (Newsreader, Inter, JetBrains Mono)
* **Utilities:** [VueUse](https://vueuse.org/)
* **Tooling:** ESLint, Vitest, Playwright
* **Hosting:** Vercel (Edge preset)

---

## 💻 Local Development

### Prerequisites

Ensure you have Node.js version **>= 22.0.0** installed.

### Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/manzoliw/manzoli.dev.git
   cd manzoli.dev
   ```

2. **Install dependencies:**
   ```bash
   yarn install
   ```

3. **Start the development server:**
   ```bash
   yarn dev
   ```
   Open `http://localhost:3000` in your browser.

### Scripts

* `yarn dev`: Starts the Nuxt development server with hot module replacement.
* `yarn build`: Compiles the application for production deployment.
* `yarn lint`: Runs ESLint checks across the codebase.
* `yarn test`: Runs unit tests using Vitest.
